# Озвучка Silero

Превращает русский текст в mp3 голосом Silero, тем же, которым озвучена
библиотека Коплстона: по умолчанию это Ксения. Перед синтезом текст
готовится для уха:

- **Числа** становятся словами в нужном падеже: «в 1265 году» звучит как «в тысяча двести шестьдесят пятом году», «около 440—430 до н. э.» как «около четыреста сорокового — четыреста тридцатого года до нашей эры».
- **Латынь** переписывается кириллицей и получает ударение по латинским правилам: «a priori» звучит как «а при+ори», «Summa Theologiae» как «с+умма теол+огие».
- **Римские цифры** читаются порядковыми: «XIII век» — «тринадцатый век», «папе Иннокентию II» — «второму».
- **Номера сносок** («слова 2.») выкидываются, скобки становятся паузами.
- **Ударения** в именах и трудных словах берутся из словарей в папке `dicts/`.

## Что нужно

- Python 3.10 или новее.
- ffmpeg — для mp3 и для изменения темпа. Без него звук сохранится в WAV.
- Около 1 ГБ места: torch и модель.

Установка, один раз:

```
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install numpy num2words
```

Как поставить ffmpeg:

- **Windows:** `winget install ffmpeg`
- **macOS:** `brew install ffmpeg`
- **Linux:** `sudo apt install ffmpeg`

При первом запуске скрипт скачает модель Silero, около сотни мегабайт, в папку `~/.cache/silero-voice`.

## Как пользоваться

```
python voice.py пример.txt                          # → пример.mp3 рядом
python voice.py глава1.txt глава2.txt --out mp3/
python voice.py папка_с_текстами/                   # все .txt в папке
python voice.py пример.txt --speaker eugene --tempo 0.85
python voice.py пример.txt --dry-run                # только подготовленный текст
```

Голоса: `xenia`, `baya`, `kseniya` — женские; `aidar`, `eugene` — мужские.

Темп задаётся множителем: `1.0` — как есть, `0.85` — на 15% медленнее. Высота голоса при этом не меняется.

Если что-то звучит странно, сначала запустите с `--dry-run`. Рядом с текстом появится файл `.speech.txt`, ровно то, что уходит в синтез. Знак `+` в нём стоит перед ударной гласной.

## Как поправить ударение

Все три словаря — обычные текстовые файлы. В каждой строке слово и его чтение, разделённые табуляцией. Знак `+` ставится перед ударной гласной.

| Файл | Что в нём | Пример строки |
|---|---|---|
| `dicts/stress.tsv` | основы имён; ударение попадает во все падежи | `Гераклит	Геракл+ит` |
| `dicts/words.tsv` | точные формы обычных слов; регистр первой буквы сохраняется | `философом	фил+ософом` |
| `dicts/foreign.tsv` | немецкие, французские, английские слова | `existenz	экзист+енц` |

У «году» ударение зависит от падежа, поэтому оно ставится правилом в коде, а не словарём. «В том же год+у», но «к такому-то г+оду».

## Что внутри

| Файл | Что делает |
|---|---|
| `voice.py` | точка входа |
| `speech.py` | подготовка текста: числа, латынь, римские цифры, сноски, ударения |
| `latin.py` | латынь кириллицей с ударением |
| `tts_silero.py` | синтез: режет текст на куски, читает, склеивает, пишет mp3 |

Если модель спотыкается на каком-то куске, синтез упрощает его и пробует ещё раз, а в консоль пишет предупреждение. Одна плохая фраза не роняет всю книгу.

## Ограничения

- **Числа.** Падеж угадывается по предлогу и соседнему слову. На годах, датах и диапазонах это работает надёжно, в редких оборотах может ошибиться.
- **Правки под книги Коплстона.** В `speech.py` есть исправления ошибок распознавания именно этих сканов: «н. 9.» вместо «н. э.», «Жайдеггер». На чистом тексте они ничего не задевают.
